# Jocelyn Remington Portfolio

Static portfolio site for Jocelyn Remington's accessible digital learning and UX work, built with:

- HTML
- Bulma
- a small custom stylesheet
- a little vanilla JavaScript for the UX sample viewer

## Open locally

You can open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then open:

- http://localhost:8000

## Mouse Makers

Open `http://localhost:8000/mouse-makers/` for a self-paced mouse warm-up
for second graders preparing for Tinkercad. The portfolio includes a project card.

Five activities cover clicking, dragging, scrolling, wheel zoom, and right-button
orbit. A teacher guide includes keyboard alternatives. Read-aloud uses browser
speech synthesis. No build step, accounts, external libraries, or saved student
data are required. Refreshing clears progress. Use a two-button mouse with a
scroll wheel to practice the intended physical movements.
